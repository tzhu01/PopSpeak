# Support

Looking for help with PopSpeak? Here's where to go:

## Community

- **GitHub Discussions**: [Q&A](https://github.com/tzhu01/PopSpeak/discussions/categories/q-a) for questions and troubleshooting

## Bug Reports

If you've found a bug, please [open an issue](https://github.com/tzhu01/PopSpeak/issues/new?template=bug_report.yml) with steps to reproduce.

## Feature Requests

Have an idea? Start a [discussion](https://github.com/tzhu01/PopSpeak/discussions/categories/ideas) first, or [open a feature request](https://github.com/tzhu01/PopSpeak/issues/new?template=feature_request.yml).

## Security

Found a security vulnerability? Please report it privately via [GitHub Security Advisories](https://github.com/tzhu01/PopSpeak/security/advisories/new). See [SECURITY.md](SECURITY.md) for details.
