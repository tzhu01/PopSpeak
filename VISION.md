# Vision

## What is PopSpeak?

PopSpeak is a Windows local voice keyboard that aims to understand Chinese professional vocabulary and dialect speech better with every correction. Its primary workflow is CPU-only and fully offline.

## Core Principles

- **Privacy first**: local recognition is the default, with no mandatory account, network or telemetry.
- **Windows first**: support only what is tested end to end on ordinary Windows CPUs.
- **Open source**: MIT licensed. Transparent development, community-driven roadmap.
- **User-owned learning**: corrections and professional vocabulary stay local and remain exportable.

## Current Priorities

1. Low-latency, no-missing-first-word capture on CPU-only Windows PCs
2. Chinese professional vocabulary and safe local correction learning
3. Measured Mandarin, Cantonese and regional-accent quality
4. Trustworthy installation, updates, privacy and recovery

## Future Directions

- Signed vocabulary packs for professions and organizations
- User-controlled dialect adapters and benchmark packs
- Offline voice commands and reusable text snippets
- Privacy-preserving import/export and device migration

## What We Won't Merge

- Features that break the privacy-first principle (mandatory cloud accounts, telemetry)
- A core flow that requires cloud access or a GPU
- Complexity that doesn't serve a clear user need
