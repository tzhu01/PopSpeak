PopSpeak 0.4.2 - Windows CPU 便携版

1. 解压整个压缩包，不要只拖出 PopSpeak.exe。
2. 双击 PopSpeak.exe，首次启动默认为“默认离线识别—极速”。
3. 按住 Ctrl+/ 说话，松开后文字会写入当前光标。

无需注册即可体验默认离线识别：累计最多 200 次或 20 分钟，任一先到即结束试用；关闭重开不会重置，升级保留既有用量与激活。试用仅开放默认离线，不含精确/多语识别、热词、纠错和文字润色。录音到达剩余时长后会自动结束并转写，已有历史仍可查看、编辑、复制和删除。

进入“激活与权益”，复制本机安装码，按公众号运营方的领取流程获得本机专属激活码，粘贴后激活。激活后不再限制累计次数和累计录音时长，可使用全部本地功能；单段仍有保护上限，第三方云 API 另受厂商费用和限制约束。激活状态离线保存在本机。公开公众号入口尚未配置时不会显示假二维码；请向发行方获取公开关注入口和激活码。

默认离线、多语离线、本地文字润色和 CPU 运行库位于相对目录 models/ 与 runtimes/，无需 GPU。精确离线大组件按需下载，不随包预装；“设置 → 语音识别”提供进度、速度、失败重试、断点续传、校验、更新、删除及自定义目录。下载组件不等于获得激活权益。

精确离线安装并选用后复用常驻原生推理进程，后续录音以 PCM 通过本机命名管道送入，不会为每段录音重复加载模型。

切换识别模式后需点击“保存并应用”。热词页会区分“当前生效模式”和“尚未保存的选择”，可直接保存当前设置并应用；保存失败时实际模式不会被伪装为已切换。精确离线仍需先完成组件下载和加载。

本地文字润色默认关闭，激活后可开启。激活后可在“设置 → 热词与纠错”添加、修改个人词表。Fun-ASR-Nano 和 Local Whisper 会把正确词直接交给解码器；其他引擎使用识别后的本地规范化。添加热词只需填写正确写法，不用编造一个错词；只有已知系统经常错成什么时，才在“高级纠错”中补充“曾识别成”或拼音。新词表从下一段录音开始生效，热词是提示而非每次必中。未激活不执行词表功能，但已有词表可查看、删除。

“设置 → 场景”无需登录即可查看。“日常输入”通过剪贴板把原始结果粘贴到当前光标，完成后恢复原剪贴板；“聊天直输”轻度整理后直接输入；“会议记录”在编辑浮层中确认结果，并加入常用会议热词。点击“应用此场景”会立即保存该组设置，从下一段录音生效；恢复日常默认不会删除个人热词或历史记录。包含润色或热词的场景需本机激活。

编辑浮层支持手动复制、识别完成后自动复制、关闭时复制、单行/按句分行、去空格/标点、复制后选中、置顶与识别语言显示；选项会跨启动保存。

历史记录支持搜索、全文编辑、复制、单条删除和全部清空。删除需确认且不能撤销。

“自定义云端接口”可分别配置字节、阿里、腾讯、科大讯飞、百度或通用音频转写兼容接口。每家所需凭证与协议不同。百度本次是停止录音后返回的短语音转写；讯飞、百度每段最多 60 秒。阿里需要定期更新临时 Token。接口测试会发约 0.2 秒合成静音，可能消耗账号额度；未提供真实凭证的厂商仅完成本地协议测试。新自定义厂商凭证明文保存在本机 settings.json，请勿分享该文件。激活不包含云服务额度。

技术组件、模型来源和许可证见“关于”、高级技术信息及 licenses/；产品档位名称不改变开源许可义务。

用户配置、历史、词典、安装标识、激活与试用记录保存在 Windows 应用数据目录，不写入本便携目录。异常退出中的试用录音会保守计入已预留额度；如有异常请保留数据并联系发行方。不要删除激活记录，否则原激活码可能不再匹配。本包不含运营私钥。发布完整性可用 manifest.sha256 校验。
