PopSpeak 0.4.2 - Windows x64 完整离线便携版

开始使用：解压整个文件夹，然后双击 PopSpeak.exe。不要只从压缩包中单独运行 exe。首次启动会自动使用默认离线识别；将光标放进任意文本框，按住 Ctrl+/ 说话，松开后转写文字会写入文本框。无需注册即可试用。

本完整包已预装 SenseVoice Small INT8、Fun-ASR-Nano GGUF、Whisper Tiny / Base、Qwen2.5 本地文字润色模型及 CPU 运行库。“设置 → 语音识别”另外提供 Whisper Small Q5_1 / Large v3 Turbo Q5_0（约 190 MB / 574 MB），按需下载，不增加本包体积；普通 CPU 使用大模型可能明显变慢。切换后点击“保存并应用”。预装模型必须与 PopSpeak.exe 保持原有相对目录结构。

悬浮球：新用户默认显示在桌面工作区右下角，可拖动位置。右键选择“关闭悬浮球”会保存此偏好，但不会退出软件；可从托盘的“显示悬浮球”或“设置 → 通用”重新打开。原有用户已保存的开关偏好保留。

0.4.2：编辑浮层新增复制/自动复制、关闭时复制、单行与按句分行、去空格/标点、复制后选中、置顶、最小化和识别语言显示。热词页直接标明“解码热词”或“后处理热词”，正确词可单独添加；错词/拼音纠错收入可选高级项。场景页改为无需登录的本地预设，可一键应用日常输入、聊天直输或会议记录。

新增按需模型：Qwen3-ASR 1.7B、Cohere Transcribe 03-2026、Nemotron 3.5 ASR Streaming 0.6B、Parakeet Unified EN 0.6B。均使用内置 CPU 原生后端，首次使用需下载，未额外打入本压缩包。Parakeet 只适合英语；新后端目前整段识别，不支持录音中预览或解码热词，但正确词表会用于识别后的本地规范化。模型有固定版本、哈希校验、下载进度/速度、主备源切换、取消重试与删除。默认保存到软件旁 models/native-asr/，可改自定义目录。

POP 录音预览：无论选择哪一种主识别模型，录音时都可由独立的本地预览链路显示近似文字。采集层按 100 ms 传输同一份音频，预览识别器会聚合滚动上下文后刷新文字，并不是把每个 100 ms 片段单独识别。预览可能随上下文修正；结束录音后始终以所选主模型的完整识别结果为准，最终结果会替换预览。预览仅用于显示，不写入历史、积分或最终输出；预览过慢也不会阻塞主识别。底部箭头收起/展开不影响录音，方块结束并识别，叉号取消本段。可在通用设置关闭预览以降低 CPU 负载。

本机体验积分：从本版开始，每次成功识别有效语音满 2 秒得 1 分，每日最多 100 分；失败、取消、修改历史不计分，删除历史不扣分，旧历史不补发。积分保存在本机；公众号礼品兑换待上线，后续需服务端核验，不保证兑换或现金价值。

场景使用：打开“设置 → 场景”，查看卡片中将要改变的输出方式、润色深度和场景热词，然后点击“应用此场景”。新设置从下一段录音开始生效；“恢复日常默认”只恢复输出与润色选项，不删除个人热词或历史记录。包含热词或润色的场景需先完成本机激活。

试用权益：默认离线识别累计最多 200 次或 20 分钟，任一先到即结束；升级保留已有用量和激活状态。精确离线、多语种离线、热词、纠错及文字润色须激活后使用。预装模型不代表已激活。激活请打开“激活与权益”，复制本机安装码，向发行方获取本机专属激活码。激活状态离线保存在本机。

本包不包含个人历史、词典、第三方云 API 凭证、账号信息或运营签名私钥。云端识别仍需使用者自行配置对应厂商凭证并承担厂商费用。用户数据保存在 Windows 应用数据目录，不会随着本压缩包分发。

精确离线使用预装的常驻原生推理服务，每段 PCM 通过本机命名管道传输；运行在 CPU 上，不需要 GPU。文字润色默认关闭，可在激活后按需开启。详细说明、开源许可和第三方声明见 licenses/、LICENSE.txt 与 THIRD_PARTY_NOTICES.md。

若 Windows 缺少 WebView2 Runtime，请按微软官方提示安装。发布前可用 manifest.sha256 校验文件完整性。本版本为未签名的本地构建；公开分发前仍应完成代码签名并在干净 Windows 10/11 电脑上验证。
